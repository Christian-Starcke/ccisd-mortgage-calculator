# Fort Bend ISD mortgage calculator

Durable notes for agents. `AGENTS.md` is regenerated by `next dev`; keep project facts here.

## Do not reverse

- Live lookups plus a manual fallback. Never auto-select a parcel.
- Parcel tax rates come from `src/data/fortBendTaxUnitCodes.ts` (county Truth-in-Taxation portal). Location presets in `fortBendTaxRates.ts` are fallback only.
- Missing private-collector rates must not be treated as $0. Surface them and ask.
- Seller CAD exemptions (`HS`) do not transfer. Homestead resets on sale.
- Appraised value and listing price stay separate. Warn when they diverge.
- Appraisal cap models **purchase year + 2** (`yearsBeforeCapApplies` default 2).
- Geographic scope is Fort Bend ISD only (`S07`). Hard-warn any other school code.

## Where things live

- Engine is pure TypeScript under `src/lib`. UI never computes a payment itself.
- `buildFromState.ts` maps `CalculatorState` → engine inputs. `scenario.ts` is the engine entry. `pathRank.ts` picks the best loan + assistance stack (closest to lowest monthly and least cash at once).
- UI state, defaults, and `STORAGE_KEY` live in `src/lib/defaults.ts`. Persistence spreads defaults over stored JSON; bump the key only for incompatible shapes.
- Address search: `GET /api/address?q=`. Parcel: `GET /api/property?objectId=`.
- FBCAD `situs` LIKE is **case-sensitive**. Queries must use `UPPER(situs) LIKE …`. Drop city tokens (they fail AND-matches against CAD’s city field).
- Typing an address without picking a CAD candidate keeps the location-preset tax bill. Each device has its own `localStorage`, so phone vs laptop can disagree on the same house.
- Changing or clearing the address resets parcel-derived fields (MUD water, tax override, unknown rates, USDA, flood, new-construction). Do not leave the previous house’s extras on the next one.
- Regenerate the tax-unit table after September 30: `npm run build:tax-units`.

## HOA

CAD does not record HOA. `hoaCertainty`: `unknown` uses the location-typical midpoint (labeled estimate), `none` is $0, `known` uses `annualHoaDues`.
